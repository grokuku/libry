      Adresses internes autorisées

      Par défaut, Libry refuse toutes les adresses de votre réseau interne (10.x, 172.16–31.x, 192.168.x, localhost, 100.64.x). C'est une protection anti-SSRF : sans elle, un service extérieur pourrait faire visiter votre réseau à Libry. Ajoutez ici, une par une, les seules cibles que Libry a le droit d'atteindre. Liste vide = aucune adresse interne joignable.

      Liste blanche active. Libry peut atteindre les adresses du réseau interne listées ci-dessous (recherche, lecture de page, crawl, capture d'écran). Restent toujours refusés : file://, les métadonnées cloud (169.254.169.254) et toute redirection vers une adresse non listée.

      Noms d'hôtes recommandé

      Ex. switchy, pi-web, nas.lan, *.holaf.lan. Un nom autorisé ne peut résoudre que vers une adresse interne : s'il se met à pointer vers Internet, la cible est refusée (anti DNS-rebinding).

        Aucun nom d'hôte autorisé.

        Plages d'adresses (CIDR)

        Ex. 10.10.0.0/16, 192.168.1.0/24, 192.168.1.20/32 (une seule adresse). Une plage ouvre toutes les adresses qu'elle contient : préférez un nom d'hôte ou une plage étroite.

          Aucune plage autorisée.
